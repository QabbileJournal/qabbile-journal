# حساب‌یار ۲.۳ — راهنمای هوشمند

در این نسخه، بدون تغییر در ساختار حسابداری، یک مرکز آموزش دوزبانه به برنامه اضافه شده است. کاربران می‌توانند با جست‌وجو و ۱۳ آموزش مرحله‌به‌مرحله، کاربرد تمام بخش‌های اصلی را یاد بگیرند. دکمه راهنمای هر صفحه توضیحات مرتبط را نمایش می‌دهد و یک تور تعاملی شش‌مرحله‌ای، محل کنترل‌های اصلی را در خود برنامه مشخص می‌کند.

**نکته:** این بسته آماده جایگزینی فایل‌های نسخه قبلی در همان مسیر GitHub Pages است. اطلاعات ذخیره‌شده در همان مرورگر باقی می‌مانند، اما پیش از انتشار حتماً از آن‌ها فایل پشتیبان JSON بگیرید.
