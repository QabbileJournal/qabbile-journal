# QABBILE EDGE LAB 3.1 — ATELIER INTERFACE

**نسخه بازطراحی رابط کاربری ژورنال قبیله — ۲۸ نوامبر ۲۰۲۶**

این نسخه بر پایه ۳.۰ ساخته شده و **تمام کد اصلی JavaScript نسخه ۳.۰ بدون تغییر** حفظ شده است. ۱۴ صفحه موجود، داده‌ها، محاسبات، فرم‌ها، استراتژی‌ها، واردکننده معاملات و پشتیبان‌گیری رمزدار در ساختار قبلی باقی مانده‌اند.

## تفاوت‌های ظاهری
- طراحی جدید فضای کاری: نوار کناری عریض با گروه‌بندی، هدر فرمان و نوار مسیر برنامه.
- صفحه نخست با ترکیب متفاوت تایپوگرافی، نشان سه‌خطی، خطوط ظریف و نورپردازی کنترل‌شده.
- کارت‌های آماری با نسبت‌های بهتر، عمق کمتر، فاصله‌گذاری منظم، گوشه‌های نرم و تاکید رنگی محدود.
- بازطراحی بصری فرم‌ها، پنل‌ها، جداول، گزارش‌ها، بخش استراتژی، مربی، نمودارها و انتخاب تم.
- هماهنگی خودکار ظاهر جدید با **هر ۹ تم** قبلی؛ تم جدیدی حذف نشده است.
- ریزتعامل‌ها و افکت مداری لوگو با احترام به خاموش‌سازی جلوه‌ها و Reduced Motion.
- نمایش مستقل در موبایل (منوی پایین) و تبلت (منوی آیکنی).

## انتشار روی GitHub Pages
۱. از نسخه فعلی ژورنال **پشتیبان JSON** بگیرید و آن را خارج از مرورگر نگه دارید.
۲. ZIP انتشار را استخراج کنید و فقط فایل‌های داخل آن را در **ریشه** مخزن `QabbileJournal/qabbile-journal` آپلود و Commit کنید.
۳. در GitHub Actions از موفقیت انتشار مطمئن شوید و آدرس زیر را بررسی کنید:

`https://qabbilejournal.github.io/qabbile-journal/`

۴. در نسخه نصب‌شده (PWA) ممکن است ابتدا صفحه قدیمی دیده شود. برنامه را کاملاً ببندید و دوباره باز کنید؛ در صورت نیاز یک‌بار رفرش کنید. **داده‌های سایت و IndexedDB را پاک نکنید.**

## حفظ داده‌ها
- نام پایگاه داده: `QABBILE_OBSIDIAN_STORE_1`
- کلید محلی: `QABBILE_OBSIDIAN_DATA_V1`
- کلید انتخاب تم: `QABBILE_UI_THEME_V1`
- اطلاعات همچنان روی مرورگر همان دستگاه نگهداری می‌شوند؛ سرور/حساب کاربری جدیدی اضافه نشده است.

## نکات آزمون
در محیط تست، مرور مستقیم لوکال‌هاست توسط مرورگر محدود بود. بنابراین برای بررسی فرم‌ها و UI از بارگذاری مستقیم HTML و آداپتور آزمایشی ذخیره‌سازی استفاده شد؛ تست واقعی PWA/IndexedDB/Service Worker روی سایت HTTPS هنوز باید پس از انتشار اجرا شود.
