راهنمای انتشار QABBILE THEME STUDIO

این بسته فایل‌های وب‌اپ را در ریشه ZIP دارد. برای انتشار باید محتوای ZIP در ریشه وب‌سایت قرار بگیرد. خود ZIP را به‌عنوان برنامه در تلگرام نفرستید.

روش آزمایشی رایگان GitHub Pages:
۱. از github.com وارد حساب خود شوید. مخزن عمومی به نام qabbile-journal بسازید.
۲. ZIP را از حالت فشرده خارج کنید. فایل‌های index.html، manifest.webmanifest، sw.js، icon.svg، icon-192.png، icon-512.png و connection-test.html را در ریشه مخزن آپلود کنید.
۳. Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > Folder: /(root) > Save.
۴. بعد از فعال شدن، نشانی قابل انتشار از الگوی https://USERNAME.github.io/qabbile-journal/ خواهد بود. USERNAME نام حساب شماست. این فقط الگو است نه لینک واقعی.
۵. بدون VPN در ایران با اینترنت همراه اول، ایرانسل و اینترنت ثابت، اول /connection-test.html و بعد صفحه ژورنال را باز کنید.
۶. یک معامله آزمایشی ثبت کنید، برنامه را کامل ببندید و دوباره باز کنید تا ماندگاری داده را بررسی کنید.

احتیاط‌ها:
- GitHub Pages بدون تبلیغ اضافی در خود کد قبیله است، ولی بازشدن دامنه github.io از ایران برای همه اپراتورها تضمین نشده.
- مخزن GitHub رایگان Public است؛ کد و فایل‌های طراحی عمومی می‌شوند. اطلاعات معاملات کاربران در مخزن ذخیره نمی‌شود.
- با انتقال از netlify.app به دامنه جدید، داده مرورگر خودکار منتقل نمی‌شود. قبل از مهاجرت، از داخل ژورنال فعلی فایل پشتیبان JSON بگیرید.
- اگر تست شبکه ایران ناموفق بود، راهکار مطمئن‌تر میزبانی روی سرور داخلی ایران همراه SSL و دامنه پایدار است؛ میزبان رایگان دائمی و تضمین‌شده قابل تأیید پیدا نشده.
- اگر فایل .nojekyll در ZIP ظاهر شد، آن را هم می‌توانید قرار دهید، ولی بدون آن نیز برای این سایت استاتیک معمولاً مشکلی ایجاد نمی‌شود.
